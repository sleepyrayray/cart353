# CART 353 Final Project Plan

For my final project, I plan to create an interactive pet portrait web application. Users will choose from a small collection of 3D animal models and arrange them into a composition by moving, rotating, and scaling them. They will also be able to adjust the camera to frame their portrait.

When the composition is ready, the user can switch to Sketch Mode. This will freeze the scene and render it as a pencil drawing using non-photorealistic rendering, with outlines, shading, and cross-hatching. Simple controls will let the user adjust the line weight, hatching density, and contrast.

The project will be built with JavaScript, Three.js, and GLSL shaders. Animal models will use static poses, keeping the focus on scene composition and the pencil-sketch rendering technique.

The final portrait can be saved as a PNG. The main goal is to explore how a 3D scene can be transformed into a stylized 2D image while giving each user enough creative control to produce a unique result.
